# SchoolEvents – Училищни събития

## Описание

SchoolEvents е ASP.NET Core MVC уеб приложение за управление на училищни събития.

Приложението позволява създаване, разглеждане, редактиране и изтриване на училищни събития. Всяко събитие има категория и организатор.

Проектът е разработен с учебна цел.

## Основни функционалности

- Разглеждане на всички училищни събития
- Създаване на ново събитие
- Преглед на детайли за събитие
- Редактиране на събитие
- Изтриване на събитие
- Търсене на събития
- Разглеждане на категории
- Разглеждане на организатори
- Валидация на въведените данни
- Навигация между основните страници

## Основни модели

Приложението използва три основни Entity модела:

### Event

Съдържа информация за училищно събитие:

- Id
- Title
- Description
- EventDate
- Location
- CategoryId
- OrganizerId

### Category

Съдържа информация за категорията на събитието.

Примерни категории:

- Спорт
- Култура
- Образование
- Технологии
- Благотворителност

### Organizer

Съдържа информация за организатора на събитието:

- име
- имейл
- телефон

## База данни

Приложението използва SQL Server база данни:

`SchoolEventsDb`

Достъпът до базата данни се осъществява чрез Entity Framework Core.

За работа с базата се използва:

`SchoolEventsDbContext`

Проектът използва EF Core Migrations за създаване и актуализиране на базата данни.

## Конфигуриране на базата данни

Преди стартиране на проекта трябва да бъде зададен правилният connection string в:

`appsettings.json`

Пример:

```json
"ConnectionStrings": {
  "DefaultConnection": "Server=YOUR_SERVER_NAME;Database=SchoolEventsDb;Trusted_Connection=True;TrustServerCertificate=True;"
}
